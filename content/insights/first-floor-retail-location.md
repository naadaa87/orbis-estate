1층 상가 입지는 건물에서 임대료가 가장 높은 자리인 만큼 판단 근거도 가장 구체적이어야 합니다. 그런데 현장에서는 "자리가 좋아 보인다"는 인상으로 결정하는 경우가 적지 않습니다. 이 글은 상가 입지 조건 가운데 가시성·동선·접근성을 거리와 폭, 사람 수로 기록하는 방법을 정리합니다. 읽고 나면 후보 점포 두세 곳을 같은 기준표로 비교하고, 그 자리가 1층 임대료를 낼 만한지 판단할 수 있습니다.

## 가시성: 전면 폭·간판 위치·시야 차단물
가시성은 손님이 점포를 언제, 어디서부터 알아보는가의 문제입니다. 점포 앞에 서서 보면 다 잘 보입니다. 손님이 다가오는 방향에서 거꾸로 걸어오며 확인해야 실제 가시성이 나옵니다.

### 숫자로 적을 항목
- **전면 폭(m)**: 도로에 면한 유리면과 출입구의 실제 폭. 면적이 같아도 전면이 좁고 깊은 점포는 간판과 진열 공간이 줄어듭니다.
- **인지 거리(m)**: 주동선을 따라 걸어오며 간판이나 매장 안이 처음 눈에 들어오는 지점까지의 거리. 양방향 모두 잽니다.
- **간판 위치**: 출입구 바로 위인지, 2층 창 아래 띠 간판인지, 돌출 간판을 걸 수 있는지
- **시야 차단물 수**: 가로수, 버스정류장 쉘터, 변압기, 노점, 상습 주정차 구간, 옆 점포의 돌출 간판
- **전면 유리 비율**: 전면 가운데 안이 들여다보이는 유리면의 비율

인지 거리는 노출 시간으로 바꿔 보면 차이가 분명해집니다. 걷는 사람이 점포를 알아본 뒤 입구에 닿기까지의 시간이 곧 들어올지 말지 정하는 시간이기 때문입니다.

> [!NOTE] 노출 시간 계산 예시(가정)
> 보행 속도를 시속 4km(1분에 약 67m)로 가정합니다. 인지 거리가 30m인 점포는 약 27초, 8m인 점포는 약 7초 동안 보입니다. 같은 길에 있어도 앞 점포의 돌출 간판이나 가로수 하나로 노출 시간이 몇 배 차이 날 수 있습니다.

> [!WARN] 간판은 계약 전에 확인합니다
> 간판의 수량·크기·위치는 「옥외광고물 등의 관리와 옥외광고산업 진흥에 관한 법률」과 시행령, 시·도 조례로 정해지고, 건물마다 관리 규약이 따로 있기도 합니다. 원하는 간판을 걸 수 있는지는 관할 구청 광고물 담당 부서와 건물주에게 계약 전에 확인합니다.

## 동선: 주동선과 부동선, 그리고 '흐름 쪽'
동선은 사람이 실제로 걷는 길입니다. 상권 안에는 보행이 몰리는 주동선과, 주동선에서 갈라져 나온 부동선이 있습니다. 같은 건물 1층이라도 주동선에 면한 쪽과 이면도로 쪽은 지나가는 사람 수가 크게 다를 수 있습니다.

1. **횡단보도와 지하철 출구 방향**: 출구에서 나온 사람이 어느 쪽으로 꺾는지, 횡단보도를 건넌 사람이 점포 쪽 인도로 오는지 봅니다. 출구에서 점포 앞까지 실제 걸음 거리(m)를 적습니다.
2. **흐름 쪽인지**: 같은 길이라도 시간대마다 사람이 주로 걷는 방향과 인도가 있습니다. 출근길에 사는 커피, 퇴근길에 사는 포장 음식처럼 업종의 주력 시간대에 사람이 목적지로 가는 방향에 점포가 있는지 확인합니다.
3. **멈출 수 있는 길인지**: 인도 폭이 좁거나 차량 진출입이 잦으면 사람이 서서 보지 못하고 지나칩니다.
4. **흐름이 끊기는 곳**: 대형 주차장 출입구, 공사 가림막, 빈 점포가 이어지는 구간은 보행 흐름을 끊습니다. 점포가 그 너머에 있는지 확인합니다.

> [!TIP] 10분 계수로 비교합니다
> 주력 시간대에 점포 앞에서 10분 동안 지나가는 사람을 방향별로 셉니다. 후보지마다 같은 시간대, 같은 방법으로 세야 비교가 됩니다. 서울은 [서울시 상권분석서비스](https://golmok.seoul.go.kr)의 길 단위·건물 단위 유동인구로 시간대 분포를 먼저 보고 현장 계수와 맞춰 봅니다.

## 접근성: 단차·계단·출입구
1층이라도 들어오기 어려우면 1층의 장점이 줄어듭니다. 인도에서 매장 바닥까지 계단이 몇 단인지, 출입구가 어느 쪽에 있는지, 유모차와 배달 기사가 바로 드나들 수 있는지 확인합니다.

- **단차(cm)와 계단 수**: 인도와 매장 바닥의 높이 차이와 경사로를 둘 공간
- **출입구 폭과 위치**: 출입구가 주동선 쪽에 있는지, 건물 공용 출입구와 겹치는지
- **반층 구조**: 반지하나 반층 위로 올라가는 점포는 1층으로 표기돼도 1층 효과가 약합니다.
- **조업·배달 동선**: 물품 반입 위치, 오토바이·차량 정차 가능 여부
- **공사 조건**: 출입구나 경사로를 고치는 공사가 가능한지, 편의시설 설치 기준이 적용되는지 설계 단계에서 확인합니다.

## 코너 자리의 장점과 비용
코너 상가는 두 방향 동선에 동시에 노출되고, 전면이 두 면이라 간판과 진열을 넓게 쓸 수 있습니다. 교차로에서 신호를 기다리는 보행자와 차량에도 보입니다. 도로 모퉁이에 접한 업소에 간판 수량을 더 허용하는 기준을 둔 지자체도 있습니다.

비용도 같이 따집니다. 코너는 같은 건물 다른 호실보다 임대료와 권리금이 높게 형성되기 쉽습니다. 두 면이 유리면이면 냉난방 부하가 커지고 진열 벽면이 줄어듭니다. 모서리에 차량 진출입구, 신호등 기둥, 변압기가 몰려 있으면 오히려 가시성이 떨어지기도 합니다.

| 구분 | 코너 자리 | 중간 자리 |
|---|---|---|
| 노출 | 두 방향 동선, 교차로 대기 인구 | 한 방향 동선 |
| 전면 | 두 면, 간판·진열 면적이 큼 | 한 면 |
| 임대료·권리금 | 높게 형성되기 쉬움 | 상대적으로 낮음 |
| 내부 활용 | 유리면이 많아 벽면 진열·주방 배치에 제약 | 벽면 활용이 쉬움 |
| 맞는 업종 | 노출이 바로 매출로 이어지는 업종 | 목적 방문 비중이 큰 업종 |

## 1층과 2층 이상: 임대료와 매출 의존도
1층 임대료가 위층보다 높은 것은 지나가다 들어오는 손님을 받을 수 있기 때문입니다. 그래서 질문은 "1층이 좋은가"가 아니라 "내 매출 가운데 지나가다 들어오는 손님의 비중이 얼마인가"입니다. 그 비중이 크면 1층 임대료를 낼 이유가 있고, 예약·검색으로 찾아오는 손님이 대부분이면 2층 이상에서 같은 매출을 더 낮은 비용으로 낼 수 있습니다.

층별 임대료 차이는 상권마다 다릅니다. [한국부동산원 R-ONE](https://www.reb.or.kr/r-one/)의 「상업용부동산 임대동향조사」는 분기마다 조사 상권별 층별 임대료를 공표하며, 2026년 10월 26일 현재 최신 공표분은 2026년 2분기입니다. 오르비스 [무료 상권분석](/analysis-tool)은 이 값을 층별 참고값으로 보여 줍니다. 표본 평균이므로 개별 점포 시세는 인근 매물 조건과 함께 봅니다.

> [!NOTE] 계산 예시(가정)
> 1층 후보는 월 임대료와 관리비 합계 600만 원, 예상 월매출 4,000만 원입니다. 2층 후보는 합계 250만 원, 예상 월매출 2,500만 원입니다. 점유비용 비율은 1층 15%, 2층 10%입니다. 이 비교에서 가장 큰 변수는 2층으로 갔을 때 매출이 얼마나 줄어드는가에 대한 가정이므로, 그 근거를 동종 점포 사례로 확인합니다.

비율만 보면 2층이 유리해 보이지만, 판단은 "1층이 더 내는 비용을 1층의 추가 매출이 메우는가"로 합니다. 매출에서 원재료비와 카드 수수료 같은 변동비를 뺀 비율을 공헌이익률이라고 하면 계산식은 아래와 같습니다.

- 1층에 필요한 추가 월매출 = (1층 월 점유비용 − 2층 월 점유비용) ÷ 공헌이익률
- 위 예시에서 공헌이익률을 40%로 가정하면 (600 − 250) ÷ 0.4 = 875만 원입니다.
- 1층 예상 매출이 2층보다 월 875만 원 이상 많을 근거가 있을 때 1층이 손익상 앞섭니다. 예시에서는 차이가 1,500만 원이라 1층이 앞서지만, 그 1,500만 원이라는 가정 자체를 검증해야 합니다.

## 업종별로 먼저 볼 조건
업종마다 1층에서 얻는 가치가 다릅니다. 아래 표는 후보지를 볼 때 우선순위를 정하는 일반적인 기준입니다. 브랜드나 운영 방식에 따라 순서는 바뀔 수 있습니다.

| 업종 | 먼저 볼 조건 | 같이 확인할 것 | 1층 의존도 |
|---|---|---|---|
| 카페 | 출근·점심 동선의 흐름 쪽, 인지 거리, 전면 유리 | 테이크아웃 대기 공간, 급배수 | 높음 |
| 음식점 | 점심·저녁 유동, 간판 노출, 대기 공간 | 배기·덕트 경로, 전력·가스 용량 | 중간~높음 |
| 편의·생활 | 주거 동선, 단지 출입구와의 거리, 야간 조명 | 물품 반입, 심야 영업 가능 여부 | 높음 |
| 리테일 | 전면 폭, 진열 가시성, 쇼핑 동선의 연속성 | 주변 점포 업종 조합, 창고 공간 | 높음 |
| 서비스(미용·교육·의원 등) | 검색·예약 접근성, 주차, 엘리베이터 | 간판 위치, 층고, 소방·피난 조건 | 낮음~중간 |

## 시간대별 현장 관찰 기록 양식
같은 점포도 시간대가 바뀌면 다른 자리처럼 보입니다. 최소한 평일 점심, 평일 저녁, 주말 오후는 나가서 같은 양식으로 적습니다. 업종의 주력 시간대가 따로 있다면 그 시간을 추가합니다.

| 기록 항목 | 평일 08~10시 | 평일 12~13시 | 평일 18~20시 | 주말 14~16시 |
|---|---|---|---|---|
| 10분 보행자 수 (방향 A / 방향 B) | | | | |
| 멈춰 서거나 들어가는 사람 수 | | | | |
| 주 연령대·동행 형태 | | | | |
| 30m 앞에서 간판 인지 (예·아니오) | | | | |
| 시야 차단 요인 (주정차·노점·적치물) | | | | |
| 인근 동종 점포 손님 수 | | | | |
| 메모 (소음·조명·분위기) | | | | |

> [!CHECK] 계약 전 마지막 점검
> - 인지 거리를 주동선 양방향에서 쟀는가
> - 주력 시간대 10분 계수를 두 번 이상 했는가
> - 원하는 간판을 걸 수 있는지 구청과 건물주에게 확인했는가
> - 단차와 출입구 공사 가능 여부를 확인했는가
> - 1층 임대료를 반영한 점유비용 비율을 계산했는가

## 오르비스는 이렇게 봅니다
1층 입지는 좋고 나쁨보다 "이 업종이 이 임대료를 낼 만큼 이 자리에서 손님을 받는가"로 판단합니다. 오르비스는 후보 점포를 볼 때 주동선 양방향의 인지 거리, 주력 시간대 계수, 출입구 조건을 같은 양식으로 기록하고 층별 임대료 참고값과 함께 비교표로 정리합니다.

후보지 주소가 있다면 [무료 상권분석](/analysis-tool)에서 반경 안의 동종 점포, 1층 점포 비중, 층별 임대료 참고값을 먼저 확인해 보세요. 상권 단위의 분석 순서는 [상권분석 처음 하는 법](/insights/trade-area-analysis-basics)에 정리했고, 후보지 현장 비교가 필요하면 [상권분석 상담](/contact?type=analysis)으로 이어서 진행할 수 있습니다.
